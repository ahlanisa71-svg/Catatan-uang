# CatatUang APK

1. Buat repo baru di GitHub, upload seluruh isi folder ini (termasuk folder `.github`).
2. Buka tab **Actions** > **Build APK** > **Run workflow** (otomatis juga jalan setiap push ke `main`).
3. Setelah hijau (±5 menit), buka run-nya, unduh **CatatUang-apk** di bagian Artifacts, ekstrak, lalu install `app-debug.apk` di HP.

Ubah isi aplikasi: edit `www/index.html`, commit, tunggu build lagi.
